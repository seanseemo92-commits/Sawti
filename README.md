# صوتي | Sawti

الإصدار التأسيسي الجديد **1.0**، رقم Android الداخلي **1**، معرّف التطبيق **com.sawti**.

تطبيق أندرويد عربي لدعم التواصل، مع تسع لهجات وبطاقات وصور وتسجيلات قابلة للتخصيص. المصدر المعتمد لأرقام الإصدار هو `app/build.gradle.kts`؛ يتحقق إصدار Release من تطابقها مع بيانات APK واسم الملف.

## أساس التطبيق الجديد
- توحيد زر متابعة الوضع الداكن مع المرجع الفاتح، وحماية سطر الحقوق من التمدد، واهتزاز يحترم إعداد التطبيق والنظام.
- التحقق من قاعدة البيانات والإعدادات قبل الاسترجاع والاحتفاظ بالرجوع الآمن حتى بدء التشغيل.
- حماية الصور والتسجيلات المشتركة من الحذف، وحفظ التعديلات المتعلقة بها داخل معاملات.
- نسخ احتياطية متسقة تشمل الصور والتسجيلات المشار إليها في قاعدة النسخة الجديدة.
- فصل النص الأصلي عن عرض اللهجة؛ الحفاظ على النطق والجملة المخصصين ومنع تعارض التعديلات.
- قاعدة `sawti.db` جديدة بمخطط Room 1 ومفاتيح مفاهيم فريدة؛ يحتفظ سجل التدريب بإحصاءاته بعد حذف بطاقة مخصصة.
- النسخ اليدوي بصيغة `sawti-foundation-backup` v1 فقط، مع تحقق من مخطط القاعدة والإعدادات والمرفقات. لا ترحيل لقواعد أو نسخ التطبيق التاريخية.
- يُصدّر مخطط Room إلى `app/schemas/`؛ أي تطوير لاحق ملزم بحفظ بيانات مستخدمي هذا الأساس دون مسح هدّام.

## البناء والتوقيع
JDK 17، Gradle 8.9، AGP 8.7.3، Kotlin 2.0.21.

استخدم أمرين متتابعين لتجنب تداخل KSP/Room في تصدير مخططات Debug وRelease:

```sh
gradle --no-daemon --max-workers=1 :app:testDebugUnitTest
gradle --no-daemon --max-workers=1 :app:assembleDebug :app:assembleRelease :app:lintRelease
```

فحوص PR تشغّل اختبارات الوحدة والتحقق من المخطط، ويُتاح بناء Debug وRelease غير موقّع في مسار التحقق الكامل. سير العمل `release-signed.yml` يبني APK وAAB موقّعين بمفتاح الناشر من GitHub Secrets، أو من النسخة الاحتياطية القديمة عند غياب جميع الأسرار. ويتحقق من تطابق شهادة APK وAAB ومن هوية التطبيق ورقم الإصدار، **ويفرض بصمة SHA-256 الثابتة لشهادة الناشر التاريخية** المستعملة في الإصدارات الموقّعة السابقة. يُرفع الناتج إلى Artifacts مع بصمات SHA-256، بينما النشر العام عبر GitHub Releases **معطّل** إلى حين الموافقة الصريحة. لا يُستبدل مفتاح الناشر بمفتاح Debug.

## التحديث والخصوصية
هذا الأساس يعيد تأسيس التطبيق كمنتج جديد؛ لا يقرأ قاعدة `my_words.db` التاريخية ولا يستورد نسخها. بُني ملف APK موقّع للاختبار بنجاح من الإصدار `1.0 (1)` في GitHub Actions، لكنه لم يُنشر كإصدار عام. **هذا الرقم لا يحدّث إصدار Android أقدمًا ذا `versionCode` أعلى**؛ على أجهزة تثبيت قديم، لا تحذف التطبيق أو بياناته قبل اختبار نسخة احتياطية قابلة للاسترجاع. أصبح مخطط Room `1.json` محفوظًا ومراقبًا في المصدر، وعلى أي تغيير لاحق لمسار البيانات إضافة ترحيل غير هدّام.

المستودع يبقى خاصًا لأن سجل Git القديم قد يتضمن أمثلة شخصية. لا توجد مفاتيح خاصة ضمن المصدر. النسخ السحابي التلقائي معطل؛ النسخ اليدوي متاح داخل التطبيق.

تفاصيل الحماية: `docs/restore-safety.md`، `docs/consistent-backups.md`، `docs/dialect-editing.md`، `docs/aurora-splash.md`.

الاختبارات الآلية لا تضمن غياب جميع الثغرات، ولا تستبدل تجربة التحديث والاسترجاع والصوت وإمكانية الوصول على أجهزة فعلية.
