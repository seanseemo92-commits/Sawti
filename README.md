# صوتي | Sawti

الإصدار **1.1**، رقم Android الداخلي **2**، معرّف التطبيق **com.sawti**.

تطبيق أندرويد عربي لدعم التواصل، مع تسع لهجات وبطاقات وصور وتسجيلات قابلة للتخصيص. المصدر المعتمد لأرقام الإصدار هو `app/build.gradle.kts`؛ يتحقق بناء Release من تطابقها مع بيانات APK واسم الملف. تعرض صفحة «حول صوتي» رقم النسخة المثبتة فعليًا.

## الاستخدام والتخصيص

- تشغيل مباشر للواجهة الرئيسية، مع جولة تعريفية اختيارية يمكن إعادتها من الإعدادات.
- بطاقات التواصل والأقرباء المخصصة، شريط تركيب الجمل والتدريب ومتابعة التقدم.
- تسع لهجات، أعلام للبلدان، واختيار أولي محلي للهجة يحافظ على اختيار المستخدم اليدوي.
- قسم القرآن بمصحف ذي خط مضمّن، وتشغيل وإعادة كل آية على حدة.
- صفحة «حول صوتي» باسم المطوّر إسماعيل بن سالم والتواصل عبر ismail92sa@gmail.com.
- إعدادات قابلة لتكبير الخط، مع إلغاء الصوت والمهام المؤجلة عند مغادرة التدريب أو تعليق التطبيق.

## البيانات والنسخ الاحتياطي

- قاعدة `sawti.db` بمخطط Room 1 ومفاتيح مفاهيم فريدة؛ يحتفظ سجل التدريب بإحصاءاته بعد حذف بطاقة مخصصة.
- نسخ احتياطية متسقة تشمل الصور والتسجيلات المشار إليها، مع تحقق من سلامة قاعدة البيانات والإعدادات والمرفقات قبل الاسترجاع.
- رجوع آمن عند فشل الاسترجاع، وحماية الصور والتسجيلات المشتركة من الحذف.
- فصل النص الأصلي عن عرض اللهجة والحفاظ على النطق والنصوص المخصصة.
- صيغة النسخ `sawti-foundation-backup` v1. هذا الأساس لا يستورد قاعدة `my_words.db` أو النسخ التاريخية السابقة له.
- مخطط Room مصدّر إلى `app/schemas/`؛ أي تطوير لاحق ملزم بحفظ بيانات مستخدمي الأساس الحالي دون مسح هدّام. إصدار 1.1 لا يغيّر مخطط القاعدة أو صيغة النسخ.

## البناء والتحقق

JDK 17، Gradle 8.9، AGP 8.7.3، Kotlin 2.0.21.

```sh
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease
```

البناء المحلي دون بيانات مفتاح الناشر ينتج Release غير موقّع. يتحقق مسار `signed-review-apk.yml` من الاختبارات وLint، ثم يبني Release محسّنًا بتوقيع الناشر الأصلي ويتحقق من شهادة APK ورقم الإصدار والموارد المضمنة. لا يُستخدم مفتاح Debug عند تعذر استرجاع مفتاح الناشر، ولا تُنشر مواد التوقيع الخاصة.

ينشر `publish-verified-release.yml` إصدار 1.1 من نفس الملف الذي اجتاز التحقق، بعد التأكد من نجاح التشغيل المثبّت، وثبات مصادر التطبيق والاختبارات وإعدادات البناء، وتطابق SHA-256 والتوقيع وبيانات الحزمة. يرفق الإصدار بيانات البناء والتوقيع ولقطات صفحة «حول صوتي». قد يضيف التزام النشر وثائق وسير عمل فقط إلى التزام البناء المثبت؛ معرّف التزام البناء موجود في `BUILD-INFO.txt`.

## التحديث والخصوصية

التحديث من أساس صوتي 1.0 الموقّع بهوية الناشر نفسها إلى 1.1 يحافظ على بيانات الأساس الحالي. الحزم التاريخية المختلفة أو الموقّعة بمفتاح Debug تحتاج معالجة توافق مستقلة؛ لا تحذف البيانات لتجاوز خطأ توقيع.

المستودع خاص. النسخ السحابي التلقائي معطل، والنسخ اليدوي متاح داخل التطبيق. اختيار البلد الأولي محلي ولا يحتاج أذونات الموقع. زر التواصل يفتح مسودة بريد عند الضغط ولا يرسل أي رسالة تلقائيًا.

تفاصيل التحقق: [جاهزية إصدار 1.1](docs/release-readiness-1.1.md). تفاصيل الحماية: [الاسترجاع](docs/restore-safety.md)، [النسخ المتسق](docs/consistent-backups.md)، [تخصيص اللهجات](docs/dialect-editing.md).

الاختبارات الآلية ولقطات المحاكاة لا تستبدل تجربة التحديث والاسترجاع والاستماع إلى النطق على أجهزة فعلية، ولا تضمن غياب جميع الثغرات.
