# صوتي 1.5.3 — إصلاحات اللهجات التسع

إصدار Android Release موقّع يستكمل إصدار 1.5.2 ويعتمد إصلاحات PR #41 المدمجة في main.

## ما الجديد
- معالجة 86 حالة تباين بين الكلمة المعروضة والنطق والتلميحات الصوتية في اللهجات العربية التسع.
- تحسين اتساق نصوص اللهجات ومفردات الأكلات الشعبية مع النطق المقصود.
- إضافة اختبارات دائمة ترصد اختلافات العرض والنطق لتقليل تكرارها مستقبلًا.
- الاحتفاظ بتعديلات المستخدمين وبنية قاعدة البيانات ونطق TTS المقصود دون تغييرات متعمدة لها.

## التحقق والتوزيع
- تتطلب النسخة نجاح اختبارات الوحدة وRelease Lint وبناء R8 والتحقق من توقيع الناشر الأصلي داخل GitHub Actions.
- رقم الإصدار 1.5.3؛ رقم البناء 9، حتى يمكن تثبيتها كتحديث فوق 1.5.2 الموقّع بالمفتاح نفسه.
- لم يكتمل التحقق اليدوي من النطق لجميع اللهجات على الأجهزة الحقيقية أو اختبار كل مقاسات الشاشات وإصدارات Android 8–16؛ هذه الاختبارات ما زالت مطلوبة قبل التوزيع الواسع.
- لا يتم نشر هذا الإصدار إلى Google Play تلقائيًا.
