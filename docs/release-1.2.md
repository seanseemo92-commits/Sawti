# صوتي | Sawti 1.2

- توحيد قسم التحيات مع بطاقات الأقسام الأخرى، بنفس الأبعاد والحواف والقصّ وتأثيرات الضغط.
- غلاف جديد و14 صورة واقعية متناسقة بمقاس 512×512، دون الحواف السوداء أو الأشرطة المضافة إلى الصور القديمة.
- تنويع الشخصيات والأعمار واللبس والمواقف، مع نساء بالحجاب، وتبسيط وضعيات اليدين ومراجعتها بصريًا.
- لون مرجاني أوضح للنص الأبيض، ومتناسق بين الغلاف والبطاقات ونوافذ التركيز والتعديل.
- الحفاظ على المعاني والصور المرتبطة باللهجات التسع وعلى النصوص والتسجيلات والصور الشخصية المخصصة.

الحزمة `com.sawti`، الإصدار `1.2`، رقم البناء `3`. التوقيع بهوية الناشر الأصلية، والتحديث من أساس صوتي الحالي يحافظ على البيانات. لم يتغير مخطط قاعدة البيانات أو صيغة النسخ الاحتياطي، ولا يوجد دمج مع main.

الفحوص تشمل بناء Debug وRelease، اختبارات الوحدة وLint، مقارنة هندسة غلاف التحيات بغلاف العائلة، تجربة الشبكة والبطاقة الكبيرة والوضع الداكن والخط المكبّر، وفحص التوقيع وموارد APK. لقطات التحيات ومعلومات البناء والتوقيع وبصمة SHA-256 مرفقة.

مراجعة الواجهة باللقطات الآلية لا تعوّض تجربة هاتف فعلي والاستماع إلى محرك النطق المثبت عليه.
