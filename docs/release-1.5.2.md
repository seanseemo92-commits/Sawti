# صوتي 1.5.2 — مرشح اختبار الإصلاحات

هذا مرشح إصدار للتحقق على أجهزة فعلية، وليس إعلان اعتماد للنشر العام.

## الإصلاحات
- ضبط الحفظ عند انتهاء تسجيل صوت البطاقة وحدّ الدقيقتين أو الضغط على حفظ أثناء التسجيل.
- إصلاح وصول إعداد الاهتزاز الجديد إلى زر المرافق دون إعادة تشغيل التطبيق، وإضافة نبضة متوافقة مع Android API 24–26.
- جعل معاينة البطاقة وتكبيرها ونوافذ الإضافة قابلة للتمرير وأكثر تكيّفًا مع شاشات ضيقة وخط مكبّر.
- زيادة مرونة تبويبات الأقسام وأزرار الاستماع والاتصال، مع إعلان التبويب أو وضع العرض المختار لقارئ TalkBack.
- تجهيز صوت البطاقات المخصص دون حجب واجهة المستخدم، مع إلغاء الطلب السابق والرجوع للنطق الاصطناعي عند الفشل.
- تحديث أداة فحص تثبيت APK وقائمة اختبار الأجهزة.

## التحقق المطلوب
- اختبارات وحدة Android، Gradle، Lint، مخطط Room، ومحاذاة المكتبات 16KiB.
- تثبيت التحديث الموقّع فوق 1.5.1 على جهاز اختبار دون مسح بياناته، وتجربة Honor Play 20c.
- فحص تسجيلات البطاقات، القرآن، تبديل الصوت بسرعة، الخط المكبّر، TalkBack والاهتزاز على Android 7–15.

## لم يتغير
- لا تعديل لقاعدة البيانات أو صيغة النسخ الاحتياطي.
- لا تغيير لشكل الصور أو اسم التطبيق.
- لا يُنشر المرشح على Google Play تلقائيًا.

مهلة إطفاء الشاشة بعد خمول طويل بقيت قرارًا اختياريًا مؤجلًا إلى حين تحديد السلوك أثناء التلاوة.

التفاصيل في [قائمة تحقق الأجهزة](pre-release-device-verification.md).
