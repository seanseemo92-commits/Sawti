# صوتي 1.5.4 — إصلاحات النطق واللهجات

إصدار Android Release موقّع بمفتاح الناشر الأصلي، مبني على `main` بعد دمج إصلاحات 1.5.3 وأحدث تصحيحات النطق.

## ما الجديد
- استكمال 245 تصحيحًا للكلمات المعروضة والنطق في اللهجات السعودية والعراقية والسورية والمصرية والتونسية والجزائرية والمغربية (PR #43).
- المحافظة على إصلاحات الصوت والواجهة التي أُدمجت في main قبل PR #43.
- إضافة فحوص تراجع تغطي التصحيحات الجديدة، وتحديث تقارير الكلمات التي كانت تفتقد نصوص النطق حتى أصبحت 0 حالة مفقودة.
- المحافظة على بيانات المستخدم وقاعدة البيانات الحالية دون ترحيل أو حذف.

## البناء والتوقيع
- versionName: `1.5.4`، versionCode: `10`، package: `com.sawti`.
- إصدار رسمي موقّع بالشهادة الأصلية المحفوظة في أسرار GitHub Actions، ليدعم التحديث من الإصدارات الموقّعة السابقة.
- يتم إجراء اختبارات الوحدة وAndroid Lint والتحقق من موارد القرآن وR8 والتوقيع قبل إتاحة ملفات APK وAAB.
- لا يتم النشر إلى Google Play تلقائيًا.
- المراجعة السمعية الطبيعية مع متحدثين أصليين لكل لهجة واختبارات الأجهزة المختلفة لا تزال مطلوبة قبل التوزيع الواسع.
