- [ ] لا تنسخ صور المستخدمين أو تسجيلاتهم أو ملفات النسخ الخاصة إلى issues أو تقارير Actions.

- [ ] تجربة زر المتابعة وتأثير الضغط والهزة مع تعطيل اهتزاز النظام، والتكبير، والوضعين الفاتح والداكن.
- [ ] الفئات والبطاقات: إظهار الكلمات والصور، تشغيل النطق والتلميح، إعادة فتح التطبيق دون تكرار البطاقات.
- [ ] قسم العائلة: صفات القرابة، الأقسام الفرعية وإضافة الاسم والصورة والتسجيل وتحريرها وحذفها، دون فقد وسائل شخصية أخرى مشتركة.
- [ ] التدريب: الاختيار والتذكر، التلميح والكشف والنتيجة، الخروج أثناء صوت أو تأخير ثم العودة؛ لا صوت متأخر بعد الانتقال.

- [ ] واجهة الوصول: قارئ TalkBack، اتجاه RTL، أحجام خط كبيرة، شاشة صغيرة، ومناطق لمس واضحة.

- [ ] إعادة فتح قاعدة البيانات بعد حذف وتعديل البطاقات؛ عدم تكرار المفاهيم أو مسح التخصيصات.
