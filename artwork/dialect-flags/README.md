# Dialect flags

Source: https://github.com/lipis/flag-icons/tree/main/flags/4x3 (MIT, Panayiotis Lipiridis), retrieved 2026-11-10. Upstream SVGs are retained here; license is bundled in `app/src/main/assets/licenses/flag-icons-LICENSE.txt`.

Render with CairoSVG at 144×108 pixels to `drawable-nodpi/dialect_flag_XX.png`. UI displays at 36×27dp. Native packaged images avoid dependence on device emoji flag versions, including Syria's green-white-black flag with three red stars. Fusha uses a globe because it is not one country's dialect.
